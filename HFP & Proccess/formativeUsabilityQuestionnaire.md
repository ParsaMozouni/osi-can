# Questionnaire:

**Quantitative Tasks Questions:** here is where we ask the user to perform certain tasks embedded in the website in order to see how these tasks are implemented, how much time it takes the user to perform them, do they find difficulty and so on.

1- Can you scroll down through our main page, locate the videos for testimonials and click to view them?
   - The designer should measure the time, difficult and errors the user faces to complete this task

2- Navigate the programs page and click on any program you desire.
   - Measure any errors that may occur

3- Does the user visit the different folder pages on a specific programs page?
   - The designer should measure the time, difficult and errors the user faces to complete this task

4- Navigate through the Volunteer Form.
   - The designer should measure the time, difficult and errors the user faces to complete this task

5- Can you find the Donation page?
   - The designer should measure the time, difficult and errors the user faces to complete this task

6- Navigate through the main menu and select a page you desire
   - The designer should measure the time, difficult and errors the user faces to complete this task

7- Does the user utilize the menu or page buttons on the Home page more often?
   - The designer should measure the time, difficult and errors the user faces to complete this task

8- How does the user navigate the Q&A?





**Qualitative Tasks Questions**
here we collect information from the user about their overall experience using the design, and how they felt. 
- What is the thing you most liked about our design?
- What is something you wish to be there?
- What is something you wish to change?
- Are there any features you hoped to find but you didn't?
- What was your first impression of our design (the colors, layout, text fonts, features, ect)?
- Does anything about the design stand out? Good or bad.
